{% comment %} Parcial reutilizable: tabla Grid.js con búsqueda, paginación y orden. Parámetros (usar con `only`): - container_id: id único del div contenedor - headers_json: JSON array con los encabezados (la última celda puede ser "Acciones") - data_json: JSON array de filas (cada fila es un array de strings; si hay acciones, la última celda es un objeto/JSON con detail/edit/toggle/void/reactivate) - sort_values_json: (opcional) JSON array de filas paralelo a data_json con los valores numéricos de ordenamiento. Cada celda es un número (float) si la columna correspondiente es numérica (Stock, Precio, Total, Monto...), o string vacío si se ordena por el texto visible. Si se omite, todas las columnas se ordenan lexicográficamente por la celda visible. - no_actions: pasar True (o cualquier valor verdadero) para tablas de solo lectura, sin columna de acciones - empty_message: mensaje cuando no hay registros Acciones soportadas en la última celda de cada fila (objeto JSON): - detail: URL -> icono "visibility" (Ver) - edit: URL -> icono "edit" (Editar) - toggle: URL -> mini-form POST con icono toggle_on/off (Activar/Desactivar) Anular/Reactivar facturas se hace exclusivamente desde el detalle (`/compras//`, `/ventas//`), no desde los listados. Por eso estas acciones no se serializan en las listas. {% endcomment %}
