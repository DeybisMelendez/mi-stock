{% comment %} Parcial reutilizable: tabla Grid.js con búsqueda, paginación y orden. Parámetros (usar con `only`): - container_id: id único del div contenedor - headers_json: JSON array con los encabezados (la última celda puede ser "Acciones") - data_json: JSON array de filas (cada fila es un array de strings; si hay acciones, la última celda es un objeto/JSON con detail/edit/toggle/void/reactivate) - no_actions: pasar True (o cualquier valor verdadero) para tablas de solo lectura, sin columna de acciones - empty_message: mensaje cuando no hay registros Acciones soportadas en la última celda de cada fila (objeto JSON): - detail: URL -> icono "visibility" (Ver) - edit: URL -> icono "edit" (Editar) - toggle: URL -> mini-form POST con icono toggle_on/off (Activar/Desactivar) - void: URL -> mini-form POST con icono "block" (Anular). Pide razón vía window.prompt() antes de enviar. - reactivate: URL -> mini-form POST con icono "restore" (Reactivar). Pide confirmación vía window.confirm() antes de enviar. {% endcomment %}
